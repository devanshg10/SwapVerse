# 🔄 SwapVerse — Real-Time AI Face Swap

> A real-time face-swapping desktop application built using Python and OpenCV.

SwapVerse uses computer vision techniques to detect faces through a webcam and perform real-time face swapping.

## ✨ Features

- 🎥 Real-time webcam processing
- 👤 Face detection
- 🔄 Real-time face swapping
- 🖥️ Interactive desktop interface
- ⚡ Real-time computer vision processing
- 📸 Face swap output

## 🛠️ Technologies Used

- **Python**
- **OpenCV**
- **Computer Vision**
- **Tkinter**

## 🧠 How It Works

1. The application accesses the webcam feed.
2. OpenCV detects faces in the video stream.
3. Facial features are processed to identify the required regions.
4. The face transformation is performed in real time.
5. The processed frame is displayed through the desktop interface.
